# Data Structures and Algorithms

A collection of C++ programs, lab tasks, assignments, quizzes, and practice exercises for the **Data Structures and Algorithms (DSA)** course.

## Repository Structure

- `lab_tasks/` — all lab and task collections, grouped in one place.
  - `lab_task_1/` — files from the original `lab_!` folder (Lab Task 1).
  - `lab_task_2/` — files from the original `lab_2` folder.
  - `task#.../` and `tsk#.../` — original numbered task collections.
  - `labs/` — standalone lab-related files that were previously in the repository root.
  - `all_task/` — the existing combined task collection.
- `assignments/` — assignment files that were previously in the repository root.
- `practice/` — standalone C++ practice programs.
- `quizzes/` — quiz-related files.
- `resources/` — PDF and document resources.
- `compiled/` — existing compiled outputs and extensionless files from the repository root.

## Language and Tools

- **Language:** C++
- **Compiler:** GCC (`g++`) or another compatible C++ compiler
- **Editor:** Visual Studio Code or any C++ IDE

## Compile and Run a C++ Program

Compile a source file from the repository root:

```bash
g++ path/to/program.cpp -o program
```

Run on Linux/macOS:

```bash
./program
```

Run on Windows PowerShell:

```powershell
.\program.exe
```

Replace `path/to/program.cpp` with the path to the source file you want to run.

## Notes

- Existing source-code contents and filenames have been preserved.
- Task and lab collections have been grouped under `lab_tasks/` to make the repository easier to navigate.
- Some programs may be independent exercises and may require their own input or setup.
